# AP Plus IT SYSTEMS

## Business Requirements

- Network monitoring, Ticketing, Helpdesk and Asset management.
- Tracks, manage, and discover all company hardware assets.
- Map assets relationships with CMDB to understand IT environment better.
- Manage Software and ensure compliance and sail through audits easily.
- Track IT asset purchases and contracts to manage IT budget better.
- IT ticketing management to take action, monitor and track on ticket request from employees.
- Should support other ITSN process like incident reporting, project management.
- Contains dashboard and KPI for overall IT management monitoring.
- Contains Settings for overall system configuraition managed and can be accessed entirely only by admins.

## Technical Details

- Implemented as a modern NextJS app, client-side rendered
- With backend and database, and data should persist
- Use popular libraries
- Create with a modern and elegant UI
- Use the best, tried and tested UI/UX approach
